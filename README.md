# Todo Task CRUD API

A lightweight, in-memory CRUD API built using Python and FastAPI to manage a to-do task list.

## 🚀 How to Install & Run

Ensure you have Python 3.10+ installed. Then run the following single command in your terminal to install dependencies and launch the server:

```bash
pip install fastapi uvicorn && uvicorn main:app --reload
